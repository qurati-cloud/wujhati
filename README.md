# Wujhati | وجهتي
Static PWA and local admin editor. Publish root main through GitHub Pages. Admin: /admin.html; draft changes stay in browser; export config.json and replace it in GitHub with an authenticated account. No credentials or private data in public config. No live bookings, commissions, VPN tunnel, analytics, or central backend. Public providers are direct links until approved affiliate links are entered. Ads require approval. Darbna is linked externally; verify availability before launch. No upfront paid services. Offers, destinations, theme and contact settings are preparatory. Partner applications are not submitted. External content is outside Wujhati's control.
